# TIBOX Cloud WordPress

Repositorio del sitio **cloud.tibox.cl**.

## Componentes

- `tibox-core/` — plugin TIBOX Core (catálogo, Slider Home, importación/exportación y Design Packages).
- `tibox-theme/` — theme TIBOX para renderizado, Header/Footer globales, plantillas y soporte de Design Packages.

## Versiones actuales

- TIBOX Core: **0.4**
- TIBOX Theme: **0.6**

## Flujo de diseño

Los diseños completos pueden importarse como **TIBOX Design Packages ZIP** desde WordPress. Un paquete activo reemplaza el contenido de la plantilla correspondiente, manteniendo Header, Footer, SEO y la infraestructura de WordPress.
